
### GitHub Issue Convention

#### 1. Title Tag

* **FEAT**: 신규 기능
* **FIX**: 버그 수정
* **UI**: 디자인, 레이아웃
* **DOCS**: 문서 수정
* **REFAC**: 코드 개선
* **CHORE**: 단순 수정/설정

#### 2. Issue Template

```markdown
### 개요
- 작업 목적 및 핵심 요약

### 상세 작업
- [ ] 세부 단위 01
- [ ] 세부 단위 02
- [ ] 세부 단위 03

### 완료 조건
- 결과물이 의도대로 동작하는지 확인하는 기준

```

#### 3. Rules

* **Small Step**: 하나의 이슈는 30분 내외의 작업 단위로 쪼개기.
* **Link**: 커밋 메시지에 `#이슈번호` 포함하기.
* **Focus**: 반드시 이슈에 정의된 '상세 작업'만 수행하기.
